# Poker Analytics Platform - AI Context

## Project Vision

Create a modern poker tracking and analysis platform that can compete with PokerTracker and Hand2Note.

The product should provide:
- Professional poker tracking
- Advanced analytics
- Hand replay
- Modern UX
- AI-assisted insights
- Future cloud features

## Current Phase

Planning and architecture design.

## Technology Stack

Backend:
- Java
- Spring Boot

Database:
- ClickHouse

Frontend:
- React
- TypeScript

Desktop:
- Tauri

## Architecture Principles

- Local-first architecture.
- Keep raw hand histories available for reproducibility.
- Separate domain logic from infrastructure.
- Statistics must be recalculable.
- Design for future cloud synchronization.

## Development Rules

- Do not make architectural changes without discussion.
- Prefer maintainable solutions over quick hacks.
- Document important technical decisions.
- Keep modules independent.

## Product Principles

- UX is a competitive advantage.
- Performance matters.
- The application should feel modern and professional.
